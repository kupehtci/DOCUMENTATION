# Azure Key Vault

The <span style="color:DodgerBlue;">Azure Key Vault</span> is a cloud serverless service for storing and accessing secrets, cryptographic keys and certificates used in cloud applications and services. 

it can store:
* **Secrets**: API keys, passwords, connection strings and tokens. 
* **Keys**: Cryptographic encryption keys for data protection. 
* **Certificates**: TLS / SSL certificates for Azure and internal resources. 

There are two tiers for this service:

* **Standard**: Secrets are protected using software libraries. It met FIPS 140 Level 1. 
* **Premium**: HSM-protected keys (Cryptographic keys generated and stored within the Hardware Security Module (HSM)).
