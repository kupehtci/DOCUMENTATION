# Microsoft Entra

Microsoft Entra its a set of identity and network access products that helps organizations to build a Zero Trust security strategy [^1]. 

Main features
* Domain Services
* Secure access for employees

## Microsoft Entra ID

**Entra ID** its the main product of entra. It offers a cloud-based identity and access management service for authentication, policy enforcement and protection for users, devices, apps and resources.

Each Entra ID is linked to an domain name that can be your organization custom domain names. 

* **Microsoft Entra Domain Services**: provides domain features like group policies, LDAP and Kerberos / NTLM authentication. 
* **Microsoft Entra Private Access**: secures the access to private applications and resources including the ones in corporate networks and multi-cloud environments. 
	* For example, a user can access a corporate network's host without using a VPN from any device. 
* **Microsoft Entra Internet Access**: secures the access to all internet resources, including the SaaS apps and Microsoft 365 applications and resources. 
* **Microsoft Entra ID Governance**: simplifies the identity and permissions management by automating the acess requests, assignments and reviews. 
* **Microsoft Entra ID Protection** detects and reports identity-based risks that administrators can investigate and automatically remediate with tools like **Conditional Access Policies**


[^1]: Zero Trust security [[Zero Trust]].
