#CONCEPTS 

# File Extensions


# Documents and office related files


| Extension                | Meaning                                        | Purpose                                                                      |
| :----------------------- | ---------------------------------------------- | ---------------------------------------------------------------------------- |
| `.txt`                   | Text File                                      | Plain Text file                                                              |
| `.md`                    | Markdown file                                  | Plain Text markdown format file                                              |
| `.doc` or `.docx`        | Microsoft Word                                 | Word file                                                                    |
| `.xls` or `.xlsx`        | Microsoft Excel                                | Excel file                                                                   |
| `.csv`                   | Comma sepparated Value                         | Column-based file with plain text separated by commas. Can be read by Excel. |
| `.pdf`                   | Portable Document Format                       | PDF Format                                                                   |
| `.odt`, `.ods` or `.odp` | OpenDocument Text, Spreadsheet or Presentation | OpenDocument format files                                                    |
| `.rtf`                   | Rich Text Format                               | Text file with basic formatting, readable across word processors            |

# Programming and source files extensions

| Extension        | Meaning                          | Purpose                                       |
| :---------------- | --------------------------------- | ------------------------------------------------ |
| `.c`             | C programming language           | C main source code file                       |
| `.cpp`           | C++ programming language         | C++ Main source code file                     |
| `.hpp` or `.h`   | C++ programming language         | C++ header code file                          |
| `.cs`            | C# programming language          | C# source code                                |
| `.py`            | Python programming language      | Python source code file                       |
| `.java`          | Java programming language        | Java source code file                         |
| `.class`         | Java bytecode                    | Compiled Java class, run by the JVM           |
| `.jar`           | Java Archive                     | Packaged Java classes and resources           |
| `.js`            | Javascript                       | Javascript source code file                   |
| `.mjs`           | Javascript                       | Javascript ES module                          |
| `.ts`            | Typescript programming language  | Typescript source code file                   |
| `.jsx` or `.tsx` | React                            | React Javascript or Typescript file           |
| `.go`            | Go                               | Go source code file                           |
| `.rb`            | Ruby                             | Ruby source code file                         |
| `.php`           | PHP                              | PHP source code file                          |
| `.swift`         | Swift programming language       | Swift source code file                        |
| `.kt` ot `.kts`  | Kotlin programming language      | Kotlin source code or script file             |
| `.rs`            | Rust programming language        | Rust source code file                         |
| `.sh`            | Shell script                     | Bash/POSIX shell script                       |
| `.ps1`           | PowerShell script                | Windows PowerShell script                     |
| `.sql`           | Structured Query Language        | SQL script with queries or DDL/DML statements |

# Other programming or data-format files

| Extension           | Meaning                            | Purpose                                                             |
| :-------------------- | ------------------------------------ | ----------------------------------------------------------------------- |
| `.yml` or `.yaml`   | YAML                                | YAML configuration file                                             |
| `.json`             | JavaScript Object Notation         | Structured, human-readable data-interchange format                 |
| `.xml`              | eXtensible Markup Language         | Tagged, hierarchical data format                                   |
| `.toml`             | Tom's Obvious Minimal Language     | Configuration file format, common in Rust/Python projects          |
| `.ini`              | Initialization file                | Simple key-value configuration file                                |
| `.env`              | Environment                        | Environment variable definitions, usually not committed to git     |
| `.html` or `.htm`   | HyperText Markup Language          | Web page markup                                                    |
| `.css`              | Cascading Style Sheets             | Web page styling                                                   |
| `.scss` or `.sass`  | Syntactically Awesome StyleSheets  | CSS preprocessor source file                                       |
| `.log`              | Log file                           | Plain text application or system log                               |
| `.lock`             | Lock file                          | Pins exact dependency versions (`package-lock.json`, `Cargo.lock`) |
| `.gitignore`        | Git ignore                         | List of paths excluded from git version control                    |

# Archive and compressed files

| Extension          | Meaning         | Purpose                                              |
| :-------------------- | ------------------ | ------------------------------------------------------ |
| `.zip`             | ZIP archive      | Common cross-platform compressed archive             |
| `.tar`             | Tape Archive     | Bundles files without compression                    |
| `.gz` or `.tar.gz` | Gzip             | Compressed file, often used together with `.tar`     |
| `.7z`              | 7-Zip archive    | High compression ratio archive format                |
| `.rar`             | RAR archive      | Proprietary compressed archive format                |

# Image, audio and video files

| Extension          | Meaning                           | Purpose                                    |
| :-------------------- | ------------------------------------ | ---------------------------------------------- |
| `.png`             | Portable Network Graphics         | Lossless compressed raster image           |
| `.jpg` or `.jpeg`  | Joint Photographic Experts Group  | Lossy compressed raster image              |
| `.gif`             | Graphics Interchange Format       | Raster image with basic animation support  |
| `.svg`             | Scalable Vector Graphics          | XML-based vector image                     |
| `.webp`            | WebP                              | Modern compressed image format             |
| `.mp3`             | MPEG-1 Audio Layer 3              | Compressed audio file                      |
| `.wav`             | Waveform Audio File Format        | Uncompressed audio file                    |
| `.mp4`             | MPEG-4 Part 14                    | Common compressed video container          |

# Executable and binary files

| Extension | Meaning              | Purpose                                     |
| :-------- | ---------------------- | ---------------------------------------------- |
| `.exe`    | Executable            | Windows executable binary                    |
| `.dll`    | Dynamic Link Library  | Windows shared library                       |
| `.msi`    | Microsoft Installer   | Windows installer package                    |
| `.app`    | Application           | macOS application bundle                     |
| `.dmg`    | Disk Image            | macOS disk image, common installer format    |
| `.bin`    | Binary                | Generic binary data file                     |
| `.iso`    | ISO 9660 image        | Optical disc image                           |

# Security related files extensions

| Extension | Meaning                     | Purpose                                  |
| :-------- | ---------------------------- | ------------------------------------------- |
| `.pem`    | Private Enhanded Mail       | Used for certficates and [[Key Pairs]]       |
| `.cer`    | Certificate                 | Certificate DER or PEM encoded           |
| `.crt`    | Certificate                 | Not encoded                              |
| `.key`    | Private Key File            | Unecrypted or encrypted                  |
| `.csr`    | Certificate Signing Request | CA exchange of certificates              |
| `.asc`    | ASCII armored               | OpenPGP and GPG keys and encrypted files |
| `.pub`    | Public Key                  | Public key of a key pair.                |
