# RHEL - Red Hat Enterprise Linux

**RHEL** means **Red Hat Enterprise Linux**: a commercial, enterprise-focused Linux distribution developed by Red Hat. It is designed for stable, secure, long-lived deployments on physical servers, virtual machines, cloud platforms, and edge environments.

## Enterprise grade

- **Stability and long support:** RHEL provides predictable release lifecycles, security patches, and support options suited to production systems.
- **Commercial subscription:** You typically pay Red Hat for support, updates, certifications, and lifecycle management rather than using a fully free community edition.
- **Broad platform support:** It runs on x86-64, ARM64, IBM Power, and IBM Z architectures, and is available across major public clouds, including Azure.
- **Security and compliance:** It includes enterprise security tooling, hardened defaults, and vendor-backed patching—common reasons organizations use it for regulated workloads.


RHEL is commonly used for:
- Application and database servers
- Kubernetes/OpenShift nodes and container hosts
- Hybrid-cloud and virtualized infrastructure
- CI/CD build agents and internal platform services
- Systems requiring vendor support, certifications, or long-term maintenance
