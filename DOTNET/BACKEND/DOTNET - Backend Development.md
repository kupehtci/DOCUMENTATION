# .NET - Backend Development

.NET is a microsoft's framework for building high performance backends with built-in security and other tools. 

It offers the following core technologies for developing Backend applications: 
* **ASP.NET Core**: the main framework for REST APIs, MVC, Razor Pages, gRPC and minimal APIs. 
* **Entity Framework Core** or **EF Core**: its the official ORM[^1]



[^1]: ORM or Object Relational Mapping
