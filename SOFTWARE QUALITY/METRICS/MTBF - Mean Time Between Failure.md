# MTBF - Mean Time Between Failure

The Mean Time Between Failure or MTBF is a software quality metric that measures the fiability and failure tolerance of a software product. 

The metric can be measured using: 

$$MTBF=\frac{T_{total} - T_{failure}}{N_{failure}}$$

Where: 
* $T_{total}$ is the total time of the software product running without failures. 
* $T_{failure}$ the time of the application misbehavior because of errors.
